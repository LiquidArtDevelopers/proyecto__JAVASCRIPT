# Introducción a JavaScript

En este curso aprenderemos los fundamentos del desarrollo web con JavaScript. Entenderemos cómo funciona el lenguaje y cómo utilizarlo para crear proyectos web dinámicos e interactivos.

## Temario

### 1. Variables

- Declaración de variables con `var`, `let` y `const`.
- Diferencias entre cada tipo de declaración y buenas prácticas de uso.
- Ámbito global, local y de bloque.
- Asignación y reasignación de valores.

### 2. Tipos de datos

- Datos primitivos: `string`, `number`, `boolean`, `null` y `undefined`.
- Datos compuestos: objetos y arrays.
- Concatenación de cadenas y plantillas literales.
- Operaciones básicas y conversión de tipos.
- Comprobación de tipos con `typeof`.

### 3. Funciones

- Declaración y ejecución de funciones.
- Parámetros y argumentos.
- Retorno de valores con `return`.
- Funciones anónimas y funciones flecha.
- Ámbito de las variables dentro de una función.

### 4. DOM y eventos

- Selección de elementos del documento.
- Modificación de contenido, atributos y estilos.
- Lectura y validación de datos de formularios.
- Gestión de eventos con `addEventListener`.
- Uso del objeto `event`.
- Aplicación práctica: desarrollo de una calculadora interactiva.


### 5. Funciones.

- Módulos (export functions).
- Funciones declarativas.
- Funciones flechas.
- Callbaks.
- Promesas y funciones flechas.
